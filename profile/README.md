# 🦁 멋쟁이사자처럼 신한대학교 — 마모키 (MAMOKEY)

> **"POSSIBILITY TO REALITY"**
> 아이디어를 현실로 만드는 곳, 멋쟁이사자처럼 신한대학교입니다.

<br>

신한대학교 소프트웨어융합학부 대표 프로그래밍 동아리 **마모키(MAMOKEY)** 는  
2026년 멋쟁이사자처럼 대학 **14기**에 합류하여 더 넓은 IT 생태계와 함께합니다.

---

## 🎯 우리의 활동

| 활동 | 설명 |
|------|------|
| 📚 **트랙별 스터디** | 기획/디자인, 프론트엔드, 백엔드 트랙으로 나뉘어 매주 정기 교육 세션 진행 |
| 🏆 **해커톤 & 아이디어톤** | 매년 1,600명 이상이 참가하는 무박 2일 해커톤에서 아이디어를 실제 서비스로 구현 |
| 🤝 **연합 활동** | 전국 멋쟁이사자처럼 대학들과 함께하는 연합 해커톤, 세미나, 네트워킹 행사 참여 |
| 💼 **프로젝트 개발** | 팀을 이뤄 실제 서비스를 기획하고 개발하며 포트폴리오 구축 |
